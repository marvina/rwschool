## ✨ 汇报工作台核心功能

1. **一键无缝切换**：顶栏分段控制器支持在 5 套方案与横向对比大厅之间毫秒级平滑切换，URL Hash 实时同步（`#01`, `#02`, `#03`, `#04`, `#05`, `#compare`）。
2. **多端视口模拟**：
   - 🖥️ **桌面端**（100% 满屏沉浸）
   - 💻 **笔记本端**（1280px 标准宽屏）
   - 📱 **移动端**（390px 真实 iPhone 视口与圆角外框，直观展示移动端自适应表现）
3. **方案设计阐述抽屉**：点击“方案阐述”可展开侧边栏，查看当前方案的设计定位、核心调色盘（含 HEX 色值）与评审考量建议。
4. **无干扰全屏汇报模式**：一键隐藏所有控制栏与浏览器边框，支持 Esc 键或极简悬浮胶囊随时退出。
5. **快捷键快速切换**（汇报演示神器）：
   - `1` / `2` / `3` / `4` / `5`：快速秒切对应方案
   - `0` 或 `C`：进入六维横向对比大厅
   - `D` / `M`：切换桌面 / 手机视口
   - `I`：展开 / 收起设计阐述抽屉
   - `F`：进入 / 退出全屏免打扰汇报
6. **方案内专属悬浮导览**：各方案在独立新标签或投影中单独打开时，右下角提供专属悬浮胶囊（在主门户内嵌时自动隐匿，保证视觉纯净）。

## 🛠️ 本地开发与构建

项目采用 `pnpm workspace` 现代 Monorepo 架构管理：

```bash
# 1. 安装依赖
pnpm install

# 2. 一键构建所有方案与主汇报工作台（生成 dist 静态包）
pnpm run build

# 3. 本地预览完整网站
pnpm run preview
# 或直接通过浏览器打开 dist/index.html
```

## ☁️ Cloudflare Pages 自动发布配置指南

本项目已预置 `_headers` 与 `robots.txt`，并且仓库中已包含构建就绪的 `dist/` 静态产物，支持两种部署方式：

### 推荐配置（从 GitHub 持续集成自动构建）：
1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)，进入 **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
2. 授权并选择 GitHub 仓库 `rwschool`。
3. 构建配置填入：
   - **Framework preset（框架预设）**：`None`
   - **Build command（构建命令）**：`pnpm run build`
   - **Build output directory（构建输出目录）**：`dist`
   - **Root directory（根目录）**：留空（默认为 `/`）
4. （环境预设已通过仓库 `.node-version` / `.nvmrc` 锁定 Node.js 22 LTS，无需手动配置）
5. 点击 **Save and Deploy** 即可完成自动部署！之后每次向 GitHub `main` 分支推送，Cloudflare 都会自动拉取最新代码并重新发布。

> **免构建极速部署（可选）**：
> 仓库的 `dist/` 目录已包含预先编译就绪的全套静态网页。如果您在 Cloudflare 中将 **Build command 留空**，构建输出目录填 `dist`，也可以直接零构建秒级发布！
